# 达妙电机规格和通讯协议

## 1. 达妙6215（关节电机）

### 基本规格
| 参数 | 值 |
|-----|-----|
| 型号 | DM6215 |
| 额定扭矩 | 12 Nm |
| 最大扭矩 | 12 Nm |
| 最大速度 | 65 rad/s (约620 RPM) |
| 减速比 | 1:1 |
| 编码器分辨率 | 16 bit |
| 工作电压 | 24V |
| 通讯接口 | CAN 1Mbps |

### 主要用途
- 腿部关节驱动（髋关节、膝关节、踝关节等）
- 需要高精度控制和位置反馈
- 支持力矩、速度、位置混合控制

## 3. CAN通讯协议

### 命令格式
```
命令帧 (主控 -> 电机):
┌─────┬─────┬─────┬─────┬─────┬─────┬─────┬─────┐
│ ID  │CMD  │P_H  │P_M  │P_L  │V_H  │V_L  │T    │
└─────┴─────┴─────┴─────┴─────┴─────┴─────┴─────┘

反馈帧 (电机 -> 主控):
┌─────┬─────┬─────┬─────┬─────┬─────┬─────┬─────┐
│ ID  │CMD  │P_H  │P_M  │P_L  │V_H  │V_L  │T    │
└─────┴─────┴─────┴─────┴─────┴─────┴─────┴─────┘
```

### 常用命令
| 命令 | 代码 | 描述 |
|-----|------|------|
| 电机使能 | 0x88 | 使能电机 |
| 电机关闭 | 0x89 | 关闭电机 |
| 设置扭矩 | 0xA1 | 纯扭矩控制 |
| 设置速度 | 0xA2 | 速度闭环控制 |
| 设置位置 | 0xA3 | 位置闭环控制 |
| 查询反馈 | 0x9A | 查询电机状态 |

### CAN ID 分配
```
命令帧 CAN ID:  0x140 + 电机ID (0-7) = 0x140-0x147
反馈帧 CAN ID:  0x200 + 电机ID (0-7) = 0x200-0x207
```

## 4. 控制模式

### 力矩控制模式
- 直接控制电机输出力矩
- 用于腿部运动控制
- 需要实时反馈
- 命令: 0xA1

### 速度控制模式
- 电机内部闭环速度控制
- 用于轮子稳定旋转
- 命令: 0xA2

### 位置控制模式
- 点对点位置控制
- 用于精确位置定位
- 命令: 0xA3

### 混合控制模式
- 同时支持位置和速度限制的力矩控制
- 最灵活的控制方式
- 推荐用于复杂运动

## 5. 通讯示例

### 启动电机
```
发送 (CAN ID 0x141, 电机1):
88 00 00 00 00 00 00 00
```

### 设置扭矩为5Nm (电机1)
```
发送 (CAN ID 0x141):
A1 00 00 14 00 00 00 00
位置: P = 0 (不使用)
速度: V = 5.12 rad/s
扭矩: T = 4 Nm (实际值 * 250)
```

### 查询电机状态 (电机1)
```
发送 (CAN ID 0x141):
9A 00 00 00 00 00 00 00

接收 (CAN ID 0x201):
F1 00 00 00 01 00 00 00
```

## 6. 数据转换

### 位置单位转换
- 内部: 0.01°
- 转换为弧度: position_rad = position_raw * 0.01 * π / 180

### 速度单位转换
- 内部: 0.01 dps (度/秒)
- 转换为 rad/s: velocity_rad_s = velocity_raw * 0.01 * π / 180

### 扭矩单位转换
- 内部: 0.001 Nm
- 转换为 Nm: torque_nm = torque_raw * 0.001
