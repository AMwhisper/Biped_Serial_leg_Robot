# Keil MDK Project

Open `RoboMasterC_WheelLeg.uvprojx` with Keil MDK 5.

## Target

- Device: `STM32F407IGHx`
- Core: Cortex-M4F
- Compiler: ARM Compiler 6
- Flash: `0x08000000`, 1 MB
- SRAM: `0x20000000`, 128 KB

## Source Layout

The project references the existing source files by relative path:

- `../src/*.c`
- `../include`
- `../../config`

The unit-test files are not included in the firmware target.

## Required Local Setup

Install the Keil STM32F4 device pack:

- `Keil.STM32F4xx_DFP`

This repository currently does not include a RoboMaster C Type CubeMX/HAL startup project. A minimal C startup/vector file and `SystemInit()` placeholder are included under `../board` so the target has an entry point. For real hardware bring-up, replace those files with board support files generated by CubeMX or supplied by DJI/ST:

- `startup_stm32f407xx.s`
- `system_stm32f4xx.c`
- HAL/CMSIS headers and sources
- CAN, GPIO, timer, UART peripheral initialization

The current `can_driver.c` and `uart_interface.c` are still abstraction stubs; bind them to the real STM32 HAL handles before motor testing.
